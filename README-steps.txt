MISSION GREEN: PUT IT ONLINE, THEN MAKE AN ANDROID APP
=========================================================
Files in this folder: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, icon-512-maskable.png

PART 1: Host it free on GitHub Pages (about 10 minutes)
1. Create a free account at github.com.
2. Click New repository. Name it mission-green. Set it to Public. Create.
3. Click "uploading an existing file". Drag in ALL 6 files from this folder (not the zip). Click Commit.
4. Go to Settings > Pages. Under Branch choose main and folder /(root). Save.
5. Wait 1 to 2 minutes. Your site is at: https://YOUR-USERNAME.github.io/mission-green/
6. Open that link on your phone to check it works.
(Alternative: drag the folder onto app.netlify.com/drop for an instant link.)

PART 2: Make the Android app with PWABuilder (about 15 minutes)
1. Go to pwabuilder.com on a laptop.
2. Paste your site link and click Start. Fix anything it flags in red (usually nothing).
3. Click Package for stores, then Android.
4. Keep the defaults. Set App name: Mission Green. Click Generate.
5. Download the zip. Inside is the .apk file and a signing key. KEEP the signing key file and password safe; you need them for future updates.

PART 3: Install on a phone
1. Send the .apk to the phone (email, Google Drive, or USB).
2. Open it. If asked, allow "Install unknown apps" for that app.
3. Tap Install. The Mission Green icon appears on the home screen.
(Google Play Store is optional. It needs a one-time $25 developer fee.)

BEFORE JUDGING
- Install it on 1 or 2 phones and test every tab.
- Tap "Load demo data" on the Home screen to show a full dashboard.
- Be ready to explain: data stays on each phone, impact numbers are estimates, reminders work while the app is open.

UPDATING LATER
Edit index.html, upload it to GitHub again. The app picks up changes the next time it opens online.
